# After Effects Basics

Micro lessons in After Effects for motion designers, by Oliver Aemisegger.
Simple shapes, clean structure, straight to the point.

Live (once published): https://luckydumpling.github.io/motion-aep/

---

## Preview locally in VS Code

You need [Node.js](https://nodejs.org) 24 LTS (once). Any version from 22 up works.

1. Open this folder in VS Code.
2. Press **⌘⇧B** (Windows: Ctrl+Shift+B). This runs the task **Preview site**.
3. Open **http://localhost:8080** in your browser.
   Inside VS Code: ⌘⇧P → *Simple Browser: Show* → paste the address.
4. Edit any file in `content/` and save. The page reloads by itself.

Stop the preview with Ctrl+C in the terminal panel.
Without VS Code: run `npm install` once, then `npm run dev`.

## Writing a lesson

One file per section. Normal markdown, plus a few blocks.

New chapters go at the end (10, 11 …). The number is part of the URL, so renumbering breaks links from the overview page.

Write "right-click" in the text: on Mac it shows as Ctrl-click, following the Mac/Win switch.

### Front matter

```yaml
---
title: Masks, Mattes + Trim Paths     # max 6 words, first word gets the squiggle
chapter: "06"
section: Masking
read_time: 6
outcomes:                             # max 3
  - Cut shapes with masks
---
```

The first paragraph after the front matter is the intro (max 2 sentences).
Each `## Heading` starts a section (1–4 per page) and appears in the section index.

### Step

```
:::step Add Trim Paths
Open the layer's Contents and add Trim Paths.
`Add > Trim Paths`
![Trim Paths properties](img/06-trim-paths.png)
:::
```

- Title max 5 words, text max 2 sentences.
- A line with only `` `code` `` becomes a **chip** (menu path, name, value)
  or a **key** if it looks like a shortcut: `` `G` ``, `` `F9` ``, `` `⌘I / Ctrl+I` ``.
  Mac / Windows pairs follow the Mac/Win switch in the header.
- Media goes right of the step on wide screens:
  - `img/….png` screenshot
  - `video/….mp4` silent loop
  - `demo:name` code demo from `site/js/demos/name.js`
  - Missing files show a clean placeholder until you add them.

### Tip and warning

```
:::tip
Trim Paths only works on a stroke. No stroke, no line.
:::

:::warning
Clarify the formats before you start.
:::
```

Max 2 tips and 1 warning per page.

### Exercise (one per page)

```
:::exercise One circle, four techniques
starter: none                      # none · continue 03 · downloads/file.zip
result: demo:masking-set           # demo:name · video/….mp4 · img/….png

1. Create a comp and draw a filled circle.
2. …
:::
```

Max 8 steps. Students can tick them off; their browser remembers it. Ticks are stored by the step's text: add or remove steps any time, only a reworded step loses its tick.

`starter: none` shows "Same project, new comp in comps > maincomps". Name new comps `motion_design_basics_NN_topic`.

## Media rules

1. **Code demo** whenever possible.
2. **Screenshot** when the point is *where* something is in After Effects.
3. **Silent loop** only for a real UI gesture: MP4 (H.264), no audio,
   max 1280 px wide, ideally under 2 MB. No GIFs.

## Publishing (later)

1. Create the repo `motion-aep` on GitHub and push this folder to `main`.
2. On github.com: **Settings → Pages → Source: GitHub Actions**.
3. Every push to `main` builds and publishes the site (about a minute).
